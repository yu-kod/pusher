PUSHER TABLE

3〜4人 ／ 13ラウンド ／ メダルゲームのプッシャー台をカードとダイスで囲むゲーム

どんなゲームか

ゲームセンターのプッシャー台を、1台だけ卓の真ん中に置いて全員で共有する。コインはカードで表す。手札のカードをレーンへ投入すると、 そのレーンに溜まっていたカードが押し込まれ、同じ枚数が反対の端から落ちる。落ちたカードのコイン数がそのまま点になる。

投入が成功するかぎり、同じラウンドの中で何度でも続けられる。ただし稼いだ点は降りるまで自分のものにならない。 ダイスで6が出ると「横穴」に落ち、そのラウンドの稼ぎはすべてジャックポットへ消える。 どこで降りるかがこのゲームのすべてで、早く降りた人は次のラウンドで先に動ける権利（先行権）を手に入れる。

中身

  • コインカード 88枚 — 1コイン40枚・2コイン35枚・3コイン13枚
  • イベントカード 16枚 — なだれ5・横穴開放5・投入口増設3・抽選抽選3（コイン札と合わせて山札104枚）
  • ボール札 3枚 — レーンの中で1枚だけ表向きに置かれる、10点のカード
  • 各プレイヤーのカード 5枚ずつ — レーン指定（左・中央・右）3枚、降りる1枚、プレイヤーカード1枚
  • 台紙1枚（3本のレーン）、トラック1枚、個人マット（1人1枚）、マーカー
  • 6面ダイス 1個（別途用意する）

台紙の見かた

台紙は落下口を卓の中央に、投入口を自分たち側に向けて置く。カードは1本のレーンにつき、上から下へこの順に並ぶ。

落下口 押し出されたカードが落ちてくる場所。ここに落ちたぶんが点になる。
レーン 裏向きのカード13枚の列。端をずらして重ねる。ボール札だけが表向きで、あと何枚で落ちるかが全員に見えている。
滞留エリア 投入されたカードと、押し出しに失敗したカードが裏向きで溜まる場所。枚数は全員に公開。
投入口 投入したカードを表向きで置く場所。判定が終わったら裏返して滞留エリアに加える。

勝ち方

13ラウンドが終わった時点で、得点がいちばん多い人の勝ち。手札は1点にもならない。投入して落とさなければ点にならない。

1

準備

  1. ボール札3枚を脇に取り分ける。残りの104枚をよく切って山札にする。
  2. 台紙の各レーンに、山札から12枚ずつ裏向きで並べる（落下口の側から順に置く）。端をずらして重ね、枚数が数えられるようにする。台紙からはみ出してよい。
  3. 続けて各レーンの滞留エリアに9枚ずつ裏向きで並べる。
  4. ボール札を各レーンに1枚ずつ、レーンのいちばん奥（＝滞留エリア寄りの端。落下口からいちばん遠い位置）に表向きで加える。これで1本のレーンは13枚になる。
  5. 席順を決める（じゃんけんなど）。先行権の列に、その順でプレイヤーカードを左から並べる。これが第1ラウンドの解決順になる。
  6. 手札を配る。先行権が前の人ほど少ない。1番目5枚、2番目6枚、3番目7枚、4番目8枚。 配る途中でイベントカードが出たら脇に置いて引き直し、配り終えたら脇のイベントカードを山札に戻して切り直す。
  7. 全員の得点マーカーを得点トラックの0に、ジャックポットの黒マーカーも0に、JPカウンターを0に、ラウンドマーカーを1に置く。
  8. 各自、個人マットの未確定得点マーカーを0に置く。手札は自分だけが見る。

なぜ最初から9枚も溜まっているのか

空の台から始めると、最初に動く人はカードを1枚押し込むだけで終わり、あとの人のために機械を充填する係になってしまう。 最初から詰まっている状態にすることで、全員が同じ条件で始められる。手札の枚数に差をつけているのも同じ理由で、 先に動ける人ほど厚い滞留を刈れるぶん、弾薬を少なくして釣り合いを取っている。

ゲームの流れ

ゲームは13ラウンド。1ラウンドは「ティック」の繰り返しでできている。

ラウンド開始（全員が参加中）
　├ ティック1：全員が同時に宣言 → 一斉公開 → 先行権の順に1人ずつ解決
　├ ティック2：まだ降りていない人だけで、同じことを繰り返す
　└ 全員が降りた（または横穴・手札切れで抜けた）→ ラウンド終了。全員3枚ドロー

ティックの3拍

① 宣言 参加中の全員が同時に、自分のマットへ2枚を伏せて置く。
レーン指定カード1枚＋投入する手札1枚。または「降りる」カード1枚だけ。
② 公開 全員が伏せ終わったら、せーので全部表にする。
誰がどのレーンを狙ったかが、解決の前に全員へ見える。
③ 解決 先行権の列の順に、1人ずつ解決する。
盤面が2か所同時に動くことは一度もない。
「降りる」も伏せて出す。降りたことが先に見えてしまうと、残った人が「あのボール札は自分まで残る」と分かった状態で投入先を選べてしまう。 遅く決めた人が得をしないように、降りる宣言も他と同じく伏せる。

③ 解決のしかた

  • 「降りる」を出していた人 — 未確定得点をそのまま得点トラックへ移して確定させる。プレイヤーカードを先行権の列の左から空いている枠へ置き、 このラウンドはもう参加しない。
  • 投入を出していた人 — 次のページの「投入の解決」を行う。

参加中の人が全員いなくなったらラウンド終了。各自山札から3枚ドローし、ラウンドマーカーを1つ進めて次のラウンドへ。 先行権の列はそのまま、次のラウンドの解決順になる。

2

投入の解決

  1. 宣言したレーンの投入口に、投入するカードを表向きで置く。
  2. 目標値を数える。

    目標値 ＝ 投入したカードのコイン数 ＋ そのレーンの滞留エリアにすでにある枚数

    いま置いたカードは数えない。滞留が厚いレーンほど目標値が高く、成功しやすい。
  3. d6を1個振る。
    出目6 横穴。押し出しを通常どおり処理してから、次ページの横穴の処理を行う（目標値がいくつでも同じ）。
    出目 ≦ 目標値 成功。押し出しを処理する。
    出目 > 目標値 失敗。投入したカードを裏返して滞留エリアのいちばん投入口寄りに加える。それで終わり。
  4. 押し出し（成功・横穴のとき）
    • 押し込み — 滞留エリアのレーンに近い側から、下の枚数ぶんをレーンの列の端へ押し込む。滞留が足りなければ、あるぶんだけ。
    • 落下 — 押し込んだのと同じ枚数が、レーンの落下口側の端から落ちる。
    • 得点 — 落ちたカードのコイン数の合計を、自分の未確定得点に加える。ボール札が落ちたら10点。 イベントカードが落ちたら、その効果を解決したうえでそのレーンからもう1枚落とす（その点も自分のもの）。
    • 片付け — 落ちたコインカードは山札のいちばん下へ。イベントカードは捨て札へ。ボール札が落ちていたら、そのレーンのいちばん奥に表向きで戻し、 その1枚下にあったカードを山札のいちばん下へ戻す（そうしないとレーンが1枚ずつ厚くなっていく）。 イベントの「もう1枚落とす」でボール札が落ちたときも同じように戻す。忘れると、そのレーンは二度とボール札を持たない。
    投入したカード 押し込む枚数（＝落ちる枚数）
    1コイン 1枚
    2コイン 1枚
    3コイン 2枚
  5. 投入したカードを裏返す。そのまま滞留エリアに残る。

全部は押し込めない

押し込める枚数はコイン数の半分（切り上げ）しかない。だから安い札で刈ろうとしても少ししか取れず、滞留は厚いまま育っていく。 熟したレーンを総取りできるのは、大きい札を持っている人だけ。そして押し込んだ枚数と落ちた枚数は同じなので、 レーンの厚みは変わらない。実機のプッシャー台と同じで、盤面のコインは増えも減りもしない。

続けるか、降りるか

解決で得た点は未確定得点として個人マットに積まれる。まだ自分の得点ではない。次のティックで投入を宣言すれば続けられるが、 横穴を踏めば積み上げた未確定得点はすべてジャックポットへ消える。

続けたティック数 1度でも横穴を踏む確率
1 16.7%
2 30.6%
3 42.1%
4 51.8%

早く降りるほど、次のラウンドで先に動ける。降りた順にプレイヤーカードが先行権の列に並び、その並びが次のラウンドの解決順になる。

あと1枚で落ちるボール札を全員が狙った場合、それを取れるのは先に解決する人である。先行権は、点を諦めて買うものになっている。

3

横穴とジャックポット

出目6は、目標値がいくつでも必ず横穴になる。安全なレーンは存在しない。

  1. 押し出しは通常どおり処理する（押し込みも落下も起きる）。落ちたぶんの点もいったん未確定得点に入る。
  2. 未確定得点をすべてジャックポットへ移す。黒いマーカーをそのぶん進める。手元には何も残らない。
  3. JPカウンターを1つ進める。
  4. そのプレイヤーはこのラウンドから抜ける。プレイヤーカードを先行権の列へ置くが、自分から降りた人より後ろに置く。

すでに確定させた得点（過去のラウンドで降りて得たもの）は失われない。

ジャックポットチャンス

JPカウンターが5に達したら、その横穴を出した人がすぐにJP判定を行う。d6を1個振り、6が出たらジャックポットの点数を全部獲得（そのまま確定。カウンターは0に戻す）。 外れたらカウンターは5のまま据え置きで、以後は誰かが横穴を出すたびに判定できる。

13ラウンドが終わってもジャックポットが残っていたら、それは流れる（誰のものにもならない）。

手札がなくなったら

投入するカードがなければ、そのラウンドはそこで終わり。未確定得点は確定する（失われない）。プレイヤーカードは、 横穴の人と同じく自分から降りた人より後ろへ置く。

イベントカード

落下口に落ちてきたイベントカードは、効果をその場で解決し、捨て札にする。そのうえでそのレーンからもう1枚落とす（その点も落とした人のもの）。 落ちたカードがまたイベントなら、同じことを繰り返す。

ラウンド終了時のドローでイベントカードを引いた場合は、その場で効果を解決して捨て札にする（引き直さない）。この場合は「もう1枚落とす」は行わず、 効果で得た点はその場で確定する。

なだれ（5枚） 全レーンの滞留を1枚ずつ押し込む。押し込んだ枚数ぶん各レーンから落ち、引いた人が得点する。
横穴開放（5枚） 1レーンを指定し、その滞留エリアをすべて表向きにする。引いた人はその中から1枚を選んで得点にし、そのカードを山札へ戻す。 残りは表向きのまま滞留し続ける。
投入口増設（3枚） 1レーンを指定してこのカードを置く。以後そのレーンには誰でも2枚同時に投入できる（目標値は2枚のコイン合計＋滞留枚数、押し込みも合計から数える）。
抽選抽選（3枚） JPカウンターを2つ進める。引いた人はすぐにJP判定を1回行える（外れてもカウンターは戻らない）。

ゲーム終了

13ラウンドが終わったらゲーム終了。山札が尽きたら、その場で捨て札を切って山札にする。それも尽きたら、引けるぶんだけ引いて続ける。

得点がいちばん多い人の勝ち。同点なら手札が多いほうの勝ち（少ない弾薬で同じ点を稼いだため）。手札も同数なら引き分け。

勝利条件

得点最多。同点なら手札が多いほう。それも同じなら引き分け。

迷いやすいところ

  • 目標値は自分の解決の直前に数え直す。先に解決した人が押し込むと滞留の枚数が変わる。宣言した時点の数字ではない。
  • 同じレーンに複数人が入ってもよい。先行権の順に1人ずつ解決し、後の人は前の人の結果が反映された盤面で判定する。
  • 未確定得点は各自のもの。他人の横穴で自分の点が消えることはない。共有しているのは台だけ。

このプロトタイプについて

これはプレイテスト用の版である。ルール本体は docs/spec.md（v0.2）と docs/turn-structure.md（ティック同時進行・ボール札・先行権）に基づく。 卓上で動かすために、文書に書かれていない運用を次のように決めてある。ここは変わる可能性がある。

レーンの深さ 各レーン12枚＋ボール札1枚の13枚（採用案 A″）。浅いレーンではボール札が1ゲームに35回落ちて「大物」にならなかった。 この深さなら3〜4ラウンドに1回に落ち着く。docs/spec.md を v0.3 に書き換える作業が進行中で、数値はそこで最終確定する。
初期手札の枚数差 手番制の「手番順が後ろほど1枚多い」を、先行権の初期順に読み替えている。
落下カードの戻し先 都度シャッフルせず山札のいちばん下へ差し込む（実装と同じ扱い）。
投入カードの見せ方 卓上版では表向きで置いてから裏返す。覚えている人が少し得をするのは、ボードゲームとして普通の範囲として残している。
宣言の締め切り 卓上版には無い。全員が伏せ終わったら開く。決めかねている人は待つ。

遊んだら教えてほしいこと

この版の目的は「同時に動いても卓がごちゃごちゃしないか」と「1ゲームが何分か」を確かめることにある。

  • 1ゲームの所要時間（準備を除く）。40〜60分と20〜30分のどちらを狙うかが、これで決まる。
  • 1ラウンドが何ティックで終わったか（目安は2〜4）。
  • 自分から降りた回数と、横穴・手札切れで抜けた回数。自分から降りるのが全体の3割を超えているか。
  • 同じティックで同じレーンに2人以上が入った回数。ボール札の取り合いが実際に起きているか。
  • 手が止まった場面。どのルールを確認するために止まったか。
  • 滞留エリアの厚み（ゲーム中の見た目で、3〜5枚あたりで推移していたか）。

印刷し直すとき

カード・トラック・個人マットは backend/ で npm run print を実行すると作り直せる。 枚数やコインの比率は backend/src/game/deck.ts、ラウンド数やJPの閾値は backend/src/game/balance.ts が出典で、 そこを変えて刷り直せば紙にも反映される。台紙とこのルールブックは手書きなので、数字を変えたときは直接直す。
