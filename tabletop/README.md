# 卓上版（プリント＆プレイ）

家庭の A4 プリンタで刷って、実際に人と遊ぶための一式（#91）。

ルールは `docs/spec.md`（v0.2）と `docs/turn-structure.md`（ティック同時進行・ボール札・先行権）に基づく。
卓上で動かすために決めた運用は、ルールブック最終ページの「このプロトタイプについて」にまとめてある。

## 印刷するもの

| ファイル | 枚数 | 中身 |
|---|---|---|
| `rulebook.html` | A4 6枚 | 日本語のルールブック（準備・1ラウンドの流れ・勝利条件・早見表） |
| `cards.html` | A4 14枚 | カード113枚（メインデッキ90＋ボール札3＋各プレイヤー5枚×4人） |
| `board.html` | A4 1枚 | 台紙（3本のレーン） |
| `tracks.html` | A4 1枚 | 得点・ラウンド・JPカウンター・先行権の列・マーカー |
| `player-mats.html` | A4 2枚 | 個人マット（未確定得点トラックと宣言を伏せる枠）2人分×2 |

別途、**6面ダイスを1個**用意する。

## 印刷のしかた

1. HTML ファイルをブラウザで開き、そのまま「印刷」する（Chrome / Edge / Safari）
2. 用紙は **A4**、**余白なし（または最小）**、**倍率100%**、**背景のグラフィックを印刷する** を有効にする
3. カードは **厚紙に印刷するか、印刷した紙を厚紙に貼る**。裏向きのカードが透けると滞留エリアの中身が見えてしまう
   - 手軽なのは、不透明なスリーブに普通紙といらないカードを重ねて入れる方法
4. カードは 63×88mm（市販のスリーブに入る標準サイズ）。破線が切り取り線
5. トラックのマーカーは切り取って使う。コマやおはじきで代用してもよい

## 刷り直すとき

カード・トラック・個人マットは生成物。`backend/` で次を実行すると作り直せる。

```
npm run print
```

数字の出典は1か所にまとめてある。

- 枚数とコインの比率 → `backend/src/game/deck.ts` の `DEFAULT_DECK_CONFIG`
- ラウンド数・JPの閾値・押し込み枚数 → `backend/src/game/balance.ts` の `DEFAULT_BALANCE`

`board.html` と `rulebook.html` は手書きなので、ルールを変えたときは直接直す。

## 遊んだあと

ルールブック6ページ目の「遊んだら教えてほしいこと」を見て、所要時間・1ラウンドのティック数・降りた回数などを記録しておく。
`docs/turn-structure.md` §4-5 の再検証項目と、卓上版の目標プレイ時間（40〜60分か20〜30分か）の判断材料になる。
